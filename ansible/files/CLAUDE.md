# Personal coding preferences

## Tooling
- Use pnpm, never npm or yarn.
- Use ripgrep (rg) for searching, not grep.

## Code style
- 2-space indentation in JS/TS, 4-space in Python.
- Prefer named exports over default exports.

## Workflow
- Run the test suite before suggesting a commit.
- Make minimal changes. Do not refactor unrelated code.
- After any code change, run the type checker.

## Communication
- When a task has multiple valid approaches, list the tradeoffs before picking one.
- Ask before introducing a new dependency.
